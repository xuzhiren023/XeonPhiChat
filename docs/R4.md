# R4 runtime

Phi Chat 1.6.11 packages the exact native-tested R4 kernel build from the optimization work. Its runtime identity is `knc-step3-tiles-r4-b52cb0584270b098`, based on llama.cpp `61e97998bf49c2d425563920b7e83e52b5ae57a6` and built with MPSS GCC 5.1.1 for Knights Corner.

R4 shares quantized weight decoding across sixteen input columns and activation reads across two output rows. Step3 also uses the tested FP16 conversion and FP32 attention kernels. Model weights, image preprocessing, image dimensions and arithmetic precision are unchanged. The runtime retains the existing conversation and image-prefix reuse protocol.

The optional `WIDE_TASKS` scheduling switch stays off for mixed text/image resident sessions because the producer measured regressions on short text prompts. The producer's approximately 20% image-encoder improvement used that switch enabled and is not an application performance claim. PhiChat's own measurements are recorded in [validation](VALIDATION.md).

The selected 7120P pairings are **Llama 3.3-8B Abliterated Q5_K_M** and **Huihui Step3-VL 10B Abliterated Q5_K_M**. The payload retains decode3 for other model pairings. In particular, LFM2.5-2.6B keeps decode3: testing R4 with the app's automatic 131,072-token context delayed first output by 0.9–1.3 seconds for small generation gains. Its recurrent-state reset behavior is unchanged by R4.

The 3120A keeps its previous runtime. Native results on 7120P do not qualify another card or every catalog model. A fresh source rebuild is a separate binary and does not inherit the packaged artifact's native acceptance.

Source and build instructions are in `tools/native-runner/tiles-r4`; exact artifact and source identities are in `assets/tiles-r4-build.json`. R5, R6 and R7 experiments are not enabled. The installed app labels an active R4 worker as **R4 optimized runtime**.

Thinking preferences continue to use model instructions. R4 changes numerical execution, not reasoning semantics or a native effort parameter. See [thinking controls](THINKING.md) for the measured effect and limits.
