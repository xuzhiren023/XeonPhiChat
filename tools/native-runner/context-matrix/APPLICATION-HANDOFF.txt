Source-level lead for a separate optimization pass (not implemented here):
candidate session::reset calls llama_memory_clear(..., true). The ordinary KV
and recurrent cache clear paths zero their allocated data buffers, rather than
only removing sequence metadata. This is consistent with reset cost growing
with an oversized context allocation. Investigate avoiding provably redundant
clears of already-clean state or accelerating the required zeroing, with exact
state/lifecycle tests. Do not globally change the flag to false without proving
initialization and stale-state safety for every supported memory architecture.
